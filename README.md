# 과천여자고등학교 진학상담 프로그램

학생의 내신·수능 성적을 넣으면 **성적이 비슷했던 과거 졸업생들이 어디에 지원해 어떤 결과를 받았는지** 보여주는 교사용 상담 도구.

---

## 구조

```
[GitHub Pages]  화면·계산     ← 이 저장소. 데이터 없음
[Apps Script]   5개년 지원결과 ← 열쇠를 가진 요청에만 응답
[교사 브라우저]  학생 명단      ← 실명. 어디로도 전송되지 않음
```

**5개년 지원결과**에는 이름도 학번도 없습니다. 대학·학과·전형·성적·결과뿐입니다.
**학생 명단**은 실명이 들어 있으므로 스프레드시트에 올리지 않고, 교사가 상담할 때 브라우저에서 직접 읽습니다.

---

## 설치

### 1. 스프레드시트와 Apps Script

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름은 `진학상담 데이터` 정도로.
2. 확장 프로그램 → **Apps Script**
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 `gas/Code.gs` 를 통째로 붙여넣습니다.
4. 저장한 뒤 함수 목록에서 **`설치`** 를 선택하고 실행합니다.
   권한을 묻는 창이 뜨면 허용합니다. (본인 계정의 스프레드시트를 다루는 권한입니다)
5. 실행 로그에 `설치 완료` 와 열쇠 두 개가 찍힙니다.
   **스프레드시트로 돌아가면 `설정` 시트에 교사용키·관리자키가 적혀 있습니다.**
   원하는 값으로 바꿔도 됩니다.

> 실행이 오래 걸리면서 안 끝나면 스프레드시트 탭에 권한·알림 창이 떠 있는지 확인하세요.
> 스프레드시트를 새로고침하면 상단에 **「진학상담」 메뉴**가 생깁니다. 거기서 실행해도 됩니다.

### 2. 웹앱으로 배포

Apps Script 편집기 → 오른쪽 위 **배포 → 새 배포**

| 항목 | 값 |
|---|---|
| 유형 | 웹 앱 |
| 실행 사용자 | 나 |
| 액세스 권한 | **모든 사용자** |

> 「모든 사용자」로 두어야 GitHub Pages 화면에서 자료를 받아올 수 있습니다.
> 주소를 알아도 열쇠가 없으면 아무것도 내주지 않으므로 안전합니다.

배포하면 `.../exec` 로 끝나는 주소가 나옵니다. 복사해 둡니다.

### 3. 저장소 올리기

1. GitHub에서 새 저장소를 만듭니다 (Public).
2. 이 폴더의 파일을 통째로 올립니다.
3. **`config.js` 를 열어 `GAS_URL` 에 2번에서 복사한 주소를 붙여넣습니다.**
4. Settings → Pages → Branch `main` / `(root)` → Save
5. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 가 열립니다.

### 4. 5개년 자료 넣기

관리자 주소로 접속합니다.

```
https://<계정>.github.io/<저장소>/?admin=관리자키
```

「파일 선택」에서 `○개년 대입 수시 정시 학생별 지원결과.xlsx` 를 올리고,
건수를 확인한 뒤 「시트에 반영」을 누릅니다. 30초쯤 걸립니다.

### 5. 교사에게 링크 보내기

```
https://<계정>.github.io/<저장소>/?k=교사용키
```

이 링크만 보내면 됩니다. 선생님들은 클릭 → 명단 엑셀 한 번 올리기 → 상담 시작.
저장 체크를 켜 두면 다음부터는 클릭만으로 바로 상담 화면입니다.

## 쓰는 법

**교사** — 링크 클릭 → (첫 접속만) 학생 명단 올리기 → 학급·이름으로 학생 선택

상담 유형은 세 가지입니다. 사이드바 「상담 유형」에서 바꿉니다.

| | 명단 파일 | 매칭 기준 | 보여주는 것 |
|---|---|---|---|
| 수시·정시 (3학년) | 학생부성적표 .xlsx | 내신 전교과 (+수능 등급) | 수시·정시 전체 지원 결과 |
| 정시만 (2학년 모의) | 교육청 영역별 기준 수능성적표 .xls | 수능 백분위 4과목 + 영어 등급 | 정시 지원 결과만 · 가/나/다군 |
| 과목 선택 (1·2학년) | (없어도 됨) | 희망 학문 분야 | 대학 권장과목 × 우리 학교 편제 |

「과목 선택」은 관리자가 `선택과목.xlsx` 를 올린 학교에서만 칩이 나타납니다.

2학년 모의고사 파일은 확장자가 .xls 이지만 실제로는 HTML 표입니다. 반별로 나온 파일이면 여러 개를 한꺼번에 골라 올리면 합쳐집니다.
2학년 모의고사는 재수생이 빠져 있고 범위도 좁아 실제 수능보다 백분위가 높게 나오는 경향이 있습니다. 화면에 그 경고를 항상 띄웁니다.

파일 받는 경로는 표지의 「자료 받는 방법」을 누르면 펼쳐집니다. 평소에는 접혀 있습니다.
경로 문구는 `config.js` 의 `ROSTER_STEPS`(학생부성적표)와 `MOCK_STEPS`(모의고사 성적표) 배열에 있습니다.
`MOCK_STEPS` 가 없으면 `js/main.js` 의 기본값이 쓰입니다 — 실제 메뉴 이름과 다르면 config.js 에 넣어 고치세요.

**학생 선택** — 학급은 「3학년 6반」, 학생은 「2번 권수림」으로 나옵니다.
목록에는 성적을 넣지 않습니다. 펼치면 반 전체 내신이 한 번에 보여서, 상담 중에 학부모가 다른 학생 성적까지 보게 되기 때문입니다.
선택한 학생의 성적은 바로 아래 카드에만 나타납니다.

**사례 크게 보기** — 「유사 학생」 탭에서 카드를 누르면 그 졸업생 한 명이 큰 창으로 열립니다.
「다음 사례」로 20명을 차례로 넘겨 볼 수 있고, `←` `→` 키와 `Esc` 도 됩니다.
작은 모니터에서 목록 글씨가 작아 안 보일 때 쓰라고 만든 것입니다.

**결과 필터** — 「유사 학생」 탭 첫 카드 위의 「전체 / 합격 있음 / 전부 불합」 칩으로 학생을 거릅니다.
「합격 있음」을 누르면 「카드 안에서 합격 줄만 보기」가 같이 켜져 붙은 줄만 남습니다(체크를 풀면 그 학생의 지원 전체). 추합은 합격으로 칩니다.
카드 번호는 원래 번호를 유지하고, 「크게 보기」 넘기기는 보이는 카드 사이에서만 움직입니다.

**결과 색** — 합격은 **빨강**, 추합은 주황, 최저미달은 보라, 불합·최저충족은 회색입니다.
제일 중요한 「합격」이 제일 먼저 보이도록 잡은 배색입니다.
예비번호는 호명 여부와 상관없이 결과 배지 **앞**에 붙습니다 — 「예비43 추합」, 「예비12 불합」.

지원 유형은 4년제로 고정되어 있습니다. 전문대 지원 기록은 데이터에 그대로 있고 화면에서만 빠집니다
(`js/main.js` 의 `includeVoc`).

**정시 배치** (선택) — 정시 자료나 배치기준표를 올린 학교에서만 「배치」 탭이 나타납니다.

정시 자료(`.xlsb`)를 올리면 그쪽이 우선합니다. 62개 대학 2,805개 모집단위에 대해
**우리 학생 점수와 「70%컷 학생」 점수를 같은 식에 넣어** 견줍니다.

대학마다 환산식에 붙는 표준화 상수는 재현하지 않았습니다. 그 대신 두 사람에게 **똑같은 식**을 쓰므로
앞뒤 순서는 유지됩니다. 화면의 점수는 대학이 발표한 환산점수와 다르며, **차이(±)만 의미가 있습니다.**
줄과 줄 사이의 점수는 견주면 안 됩니다 — 대학마다 척도가 다릅니다.

과목별 컷은 자료에 모두 백분위로 들어 있어 이 방식이 성립합니다.
영어·한국사 등급표는 대학마다 척도가 달라(100점·200점·150점·10점 가산·감점표) **표의 최댓값을 100으로 맞춰** 국·수·탐과 같은 자리에 놓습니다.
반영 비율 없이 가·감점으로만 두는 대학(경희·서울·고려·중앙·전남 등)은 1등급을 0으로 두고 만점 기준으로 환산해 더합니다.
학생에게 영어·한국사 등급이 없으면 컷 쪽에서도 빼서 같은 식으로 견줍니다.
국·수·탐 가중치가 자료에 없는 줄(영·한국사만 있는 성균관대 일부)과 과목별 컷을 공개하지 않은 줄은 판정하지 않습니다(2,805개 중 2,528개 판정).

판정 기준과 **우리 학교 5개년 정시 실제 합격률** — 졸업생 정시 지원 172건에 같은 계산을 돌려 맞춘 값입니다.

| 판정 | 컷과의 차이 | 실제 합격률 |
|---|---|---|
| 안정 | +3 이상 | 78% |
| 적정 | 0 ~ +3 | 76% |
| 소신 | −2 ~ 0 | 53% |
| 상향 | −5 ~ −2 | 16% |
| 도전 | −5 미만 | 6% |

컷 추이는 대학·군·**전형**·학과가 모두 같은 지난 학년도 줄에만 붙입니다(그 해 전형이 하나뿐인 학과는 전형 없이도 맞춥니다).

정시 자료 출처: YMABI 「27학년도 정시 지원가능 대학 및 학과 검색」 (github.com/YMABI/SearchUnivMajorPossibility) ·
제작자 이용허락을 받아 씁니다.

**갱신** — 관리자 화면 「정시 지원가능 자료」의 **「새 파일 확인」** 을 누르면 저장소에서 최신 파일을 확인합니다.
새 파일이 있으면 받아서 읽는 것까지 자동으로 하고, 「시트에 반영」만 누르면 끝납니다.
이미 최신이면 그렇다고 알려 주고 아무것도 받지 않습니다(파일의 sha 를 스프레드시트에 남겨 비교합니다).
받아서 읽는 데 30초쯤 걸립니다. 내려받아 둔 파일이 있으면 「파일 선택」으로 직접 올려도 됩니다.

저장소 주소는 `config.js` 의 `JG_REPO` 한 줄입니다. 파일 이름은 보지 않고 `.xlsb` 를 찾으므로
학년도가 바뀌어 이름이 달라져도 그대로 동작합니다.

**정시 배치기준표** (예전 방식) — 정시 자료가 없을 때만 씁니다.
대교협 고교용 대입상담프로그램이 같은 일을 훨씬 정밀하게 하므로, 그쪽을 쓰신다면 이 탭은 켜지 않는 편이 낫습니다.

이 탭은 대학 입학처와 대교협이 공개한 전년도 정시 입시결과(배치기준표)와 학생의 국·수·탐 백분위 평균을 비교해 안정·적정·소신·상향·도전으로 나눕니다. 처음에는 **적정**만 보여 주고, 칩으로 다른 구간도 볼 수 있습니다. 오른쪽에는 우리 학교 5개년 정시 실제 사례(유사 졸업생 / 그 학과 / 그 대학)가 함께 붙습니다.

배치기준표는 관리자가 `?admin=` 화면에서 `배치기준.xlsx` 를 올리면 들어갑니다. 대학을 더 넣으려면 엑셀에 행을 추가해 다시 올리면 됩니다 (열 설명은 엑셀의 「설명」 시트).

배치기준표는 세 곳에서 왔습니다.

| 출처 | 내용 |
|---|---|
| 대학 입학처 공개자료 (2026학년도) | 학과별 70%컷. 가장 최신 |
| 대교협 「2025학년도 대입 전형결과」 자료집 | 학과별 컷. adiga.kr 대입정보자료실의 배포용 PDF |
| 우리 학교 5개년 실적 | 위 둘이 없는 대학. 졸업생이 실제 합격한 백분위 중앙값(계열별). 화면에 「우리 학교」로 표시 |

**검증** — 대학이 공개한 수치도 산출 기준이 달라 우리 학생 백분위와 안 맞는 경우가 많습니다. 그래서 각 표의 백분위 중앙값을 우리 학교 정시 합격자의 실제 백분위 중앙값과 대조해, 차이가 8(합격 6건 미만이면 10) 이내인 표만 실었습니다. 대학 단위가 아니라 **표(페이지) 단위**로 걸렀습니다. 탐구를 공개하지 않는 대학은 국·수만으로 비교했습니다.

현재 81개 대학 1,098줄로, 우리 학교 5개년 정시 지원의 78%를 덮습니다.

**과목 선택** (선택) — 진급할 때 교과를 고르는 1·2학년 상담용입니다.

왼쪽에서 희망 **학문 분야**를 최대 3개까지 고르면, 그 분야가 요구하는 과목이 **우리 학교 편제 위에** 표시됩니다.
학기·묶음(택N)별 카드로 나오고, 과목마다 「핵심 / 권장 / 계열 공통 / 계열 권장 / 관계없음」과 근거 대학 수가 붙습니다.
카드 위에는 **확인된 것**(이미 전원이 듣는 과목 등)과 **짚어야 할 것**(자리보다 핵심 과목이 많음, 자리 초과, 함께 들을 수 없는 조합)이 문장으로 뜹니다.

탭 세 개입니다.

| 탭 | 내용 |
|---|---|
| 과목 고르기 | 편제 묶음별 과목 목록. 눌러서 체크하면 개수·시간표를 확인합니다 |
| 대학이 붙인 조건 | 「3과목 이상」, 「위계에 맞게」 같은 대학 원문 단서 |
| 우리 학교에 없는 과목 | 대학은 권장하지만 개설되지 않은 과목 (공동교육과정으로 메울지 판단) |
| 대학별 결과 | 지금 조합을 47개 대학 833개 모집단위와 하나씩 맞춰 봅니다 |

희망 분야를 바꾸면 체크는 모두 풀립니다. 새 분야는 새 상담이라 빈칸에서 시작합니다.

**대학별 결과** — 「과목 고르기」 맨 아래 <b>「이 조합으로 대학 보기 →」</b> 를 누르면 열립니다.
모집단위마다 대학이 지정한 과목을 세 가지 색으로 나눠 보여 줍니다.

| 색 | 뜻 |
|---|---|
| 초록 | 이미 들었거나 지금 고른 과목 |
| 파랑 | 우리 학교에 있는데 아직 안 고른 과목 — 어느 학기 어느 묶음인지 함께 표시 |
| 빨강 | 우리 학교에 개설되지 않은 과목 |

판정은 <b>이미 충족 / N과목 더 들으면 충족 / 우리 학교에 없는 과목 N개 / 지정 기준 없음</b> 네 가지입니다.
**「가능·불가능」으로 쓰지 않았습니다.** 권장과목은 지원 자격이 아니라 서류평가 참고 자료입니다.
안 들었다고 지원이 막히지 않으므로, 학생에게 「너는 여기 못 간다」로 전달될 표현은 쓰지 않았습니다.

「수학」·「사회」처럼 교과군으로만 지정한 대학은 그 교과군에서 **선택과목을** 한 과목이라도 들었으면 이수로 봅니다.
전원이 듣는 공통과목은 교과군 충족에 세지 않습니다.

**학년별 선택 결과** (선택) — 두 길이 있습니다.
관리자가 `?admin=` 화면 「학년별 선택 결과」에 반별 선택 명단을 올리면 **브라우저가 이름을 지우고 학급·번호·과목만** 서버에 보내고,
같은 칸에서 **학생부성적표를 함께 고르면(권장)** 이름으로 짝을 맞춰 반·번호를 학생부 기준으로 바꾸고 학생부에 없는 학생(자퇴·전학)은 뺍니다 —
선택 명단의 번호가 학생부와 다르면(번호를 새로 매긴 뒤·전) 다른 학생에게 붙기 때문입니다. 머리글은 「반·번(번호)」도 「신반·신번·구학번」도 읽습니다.
모든 선생님 화면에 자동으로 붙습니다(이름은 각 컴퓨터의 학생부 명단에서 학급·번호로 다시 붙입니다 — 명단이 없으면 「3반 12번」으로만 보입니다).
학년도를 같이 저장하므로 다음 해에 작년 자료가 붙으면 상자 띠가 노랗게 바뀌며 「작년 자료입니다」라고 표시됩니다.
또는 사이드바 「학년별 선택 결과 올리기」로 이 컴퓨터에서만 읽을 수도 있습니다(이름 포함, 서버로 가지 않음). 둘 다 있으면 이 컴퓨터 것을 씁니다.

「2학년 → 3학년 선택」 화면에서 학생을 고르면 3학년 상자 위에 **「2학년 — 지금 듣고 있는 과목」** 상자가 깔립니다.
1·2학기 이수 과목 중 이 분야와 관계있는 것을 앞에, 나머지는 「그 외」로 접고, 아래 줄에 **이 분야 핵심 과목 진행**(이수 ✓ / 3학년 어느 묶음에서 고를지 / 2학년에 안 들음)을 보여 줍니다.
3학년 선택은 이 위에서 하는 것이므로, 대학별 결과의 「이수·나중에·없음」 판정에도 2학년 이수분이 그대로 들어갑니다.

사이드바로 올리면 학교가 만든 반별 선택 명단(.xlsx)을 올리면
과목별 수강 인원과 **A·B·C 타임 배정**이 카드에 함께 나옵니다. 2학년을 고르면 그 학생이 실제로 이수한 과목도 표시됩니다.

- 이 파일은 **실명이 들어 있어 서버로 보내지 않습니다.** 브라우저(IndexedDB)에만 남고, 「이 컴퓨터에서 자료 지우기」로 지웁니다
- 학기는 시트 이름과 **파일 이름**에서 읽습니다. 파일 이름에 「2학년 2학기」처럼 들어 있어야 정확합니다. 올린 뒤 뜨는 확인창에 어떤 학기로 읽었는지 그대로 표시되니 확인해 주세요
- 타임(A·B·C)은 **올해 시간표**입니다. 내년 시간표는 아직 정해지지 않았으므로 화면에 그 문구를 항상 붙입니다. 같은 타임끼리 겹칠 때만 경고하고, 겹치지 않게 배정할 방법이 하나라도 있으면 경고하지 않습니다

**선택과목 자료** — 관리자가 `?admin=` 화면에서 `선택과목.xlsx` 를 올리면 들어갑니다.
대교협 「2028 대학 전공별 권장과목」과 서울대 「2028 전공 연계 교과이수 과목」을 학문 분야 33개로 정리한 표에,
우리 학교 편제표(공통·묶음·택N·공동교육과정)를 붙인 파일입니다.
「학교 메모 ← 선생님이 직접 쓰는 칸」에 안내를 적어 다시 올리면 그 문장이 분야 설명 아래에 그대로 나옵니다.

현재 47개 대학이 학과 단위로 권장과목을 공개했고, 이는 우리 학교 5개년 지원의 약 41%입니다.
나머지 대학은 **계열 단위** 권장만 있거나 아예 없습니다 — 「관계없음」은 "안 된다"가 아니라 **"근거 자료가 없다"** 는 뜻입니다.

**관리자** — 매년 새 지원결과 엑셀이 나오면 `?admin=` 주소에서 다시 올리면 끝입니다.

## 유사도 계산

**수시·정시 모드**
```
거리 = |내신 차이| + 0.7 × |수능 평균등급 차이|
```
수능을 입력하지 않으면 내신만으로 찾습니다. 과거 학생에게 수능 기록이 없으면 0.45를 더합니다.

**정시 모드** — 내신은 보지 않습니다.
```
거리 = 백분위 차이의 평균(국·수·탐1·탐2) + 3 × |영어 등급 차이|
```
정시 지원 이력이 있는 졸업생만 후보입니다.

`js/match.js` 의 `CSAT_WEIGHT`, `NO_CSAT_PENALTY`, `ENG_WEIGHT` 로 조정합니다.

**정시 배치 판정** — 학생 백분위 평균(국·수·탐, 탐구는 2과목 평균) − 대학 70%컷
```
안정 ≥ +2.0 / 적정 ≥ 0 / 소신 ≥ −1.5 / 상향 ≥ −3.0 / 도전 그 아래   (−6 미만·+10 초과는 표시 안 함)
```
대학이 평균만 공개한 경우 70%컷보다 0.7 높다고 보고 보정합니다(`AVG_OFFSET`). 등급만 공개한 대학은 학생 등급 평균과 비교합니다. 대학마다 탐구 반영 과목 수와 영어 처리 방식이 달라 **±2는 오차**입니다. 특히 과목별 백분위로 공개한 대학은 50%·70% 등록자 *개인*의 과목 백분위 평균이라 순위가 환산점수 기준이어서 더 흔들립니다.

같은 학과가 여러 학년도로 들어 있으면 가장 최근 학년도만 씁니다.

## 파서가 흡수하는 형식 차이

- **열 순서** — 2026 수시만 `등급 → 표준점수 → 백분위`, 나머지는 `표준점수 → 백분위 → 등급`
- **최저 표기** — `충` `충족` → 충족 / `미` `부` `불` → 미충족
- **1차 표기** — `1차합` `1차 합` → 1차합격
- **`#N/A`** 등 오류 문자열 → 빈 값
- **학생 식별** — 원본에 학번이 없어 `학년도 + 1·2학년 내신`으로 같은 사람을 찾습니다. 수시 시트는 소수 2자리, 정시 시트는 3자리라 반올림·절사 두 가지로 맞춰 봅니다. 1·2학년이 같은 다른 학생은 수능 성적(같은 시트 안에서는 전교과까지)으로 갈라 둡니다. 3학년 내신은 수시 시트가 3-1까지, 정시 시트가 3-2까지라 값이 달라 시트를 건너서는 비교하지 않습니다
- **수능 0** — 등급·백분위·표준점수의 `0`은 미응시로 보고 빈 값으로 읽습니다
- **모집시기 「추가」** — 「추가」 안의 '가'를 가군으로 읽지 않습니다
- **3학년 성적표 배치** — 머리글은 「5등급/9등급」 쌍인데 내용이 9등급 단일 열 열 개(국·수·영·사·과·수과·국수영·국수영사·국수영과·국수영사과)인 파일이 있습니다. 「5등급」 칸에 5보다 큰 값이 있거나 5등급·묶음 칸이 전부 비었으면 그 배치로 읽습니다
- **계열** — 학과명 키워드로 4계열 분류. 규칙은 `js/parse.js` 상단의 `MED` `ART` `NAT` 배열
