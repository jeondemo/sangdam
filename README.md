# 대입 상담 · 유사 사례 검색

과천여자고등학교 교사용 진학 상담 도구. 학생의 내신·수능 성적을 넣으면 **성적이 비슷했던 과거 졸업생들이 어디에 지원해 어떤 결과를 받았는지** 보여줍니다.

## 개인정보 처리

**엑셀 파일은 브라우저 밖으로 나가지 않습니다.** 서버로 전송하지 않고, 이 저장소에도 포함하지 않습니다.

- 교사가 화면에서 엑셀을 선택하면 브라우저가 직접 읽습니다
- 파싱 결과는 그 브라우저의 IndexedDB에만 저장되어 다음 접속 때 자동으로 열립니다
- 다른 사람의 브라우저에는 아무것도 남지 않습니다
- 공용 PC에서는 사용 후 「데이터 관리 → 저장된 데이터 지우기」를 눌러 주세요

저장소에는 코드만 올라가므로 GitHub Pages로 공개 배포해도 학생 실명이나 학교 대입 실적이 노출되지 않습니다.

## 필요한 파일

| 파일 | 필수 | 내용 |
|---|---|---|
| `○개년 대입 수시 정시 학생별 지원결과.xlsx` | 필수 | 학년도별 `2026학년도 수시` / `2026학년도 정시` 형식의 시트 |
| `○년 학생부성적표.xlsx` | 선택 | `analysis` 시트. 넣으면 학급·이름으로 학생을 골라 쓸 수 있습니다 |

성적표가 없어도 내신 전교과를 직접 입력해 사용할 수 있습니다.

## 배포

빌드가 없습니다. 저장소를 그대로 GitHub Pages로 올리면 됩니다.

1. 저장소 → Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `(root)`
3. 저장하면 `https://<계정>.github.io/<저장소>/` 로 열립니다

파일을 수정하고 커밋하면 1분 이내에 반영됩니다. 휴대폰의 GitHub 웹 에디터에서 바로 고칠 수 있습니다.

## 구조

```
index.html              화면 골격
css/app.css             스타일
js/parse.js             엑셀 → 데이터 변환 (연도별 열 순서 차이·표기 불일치 정리)
js/store.js             IndexedDB 저장
js/match.js             유사 학생 탐색과 집계 (순수 계산)
js/render.js            HTML 생성
js/main.js              화면 연결
vendor/xlsx.full.min.js SheetJS 0.18.5 (CDN 대신 포함 — 교내망에서도 동작)
```

## 유사도 계산

```
거리 = |내신 차이| + 0.7 × |수능 평균등급 차이|
```

- 수능을 입력하지 않으면 내신만으로 찾습니다
- 과거 학생에게 수능 기록이 없으면 0.45를 더합니다 (등급 0.64 차이에 해당)
- 거리가 가까운 순으로 설정한 인원수만큼 뽑습니다

`js/match.js`의 `CSAT_WEIGHT`, `NO_CSAT_PENALTY`를 고치면 조정됩니다.

## 데이터를 읽을 때 정리하는 것

원본 엑셀은 연도마다 형식이 조금씩 다릅니다. 파서가 다음을 흡수합니다.

- **열 순서** — 2026 수시만 `등급 → 표준점수 → 백분위`, 나머지는 `표준점수 → 백분위 → 등급`. 병합된 헤더 3줄을 조합해 열 이름을 만들어 이름으로 찾습니다
- **최저 표기** — `충` `충족` → 충족 / `미` `부` `불` `미충` → 미충족
- **1차 표기** — `1차합` `1차 합` `1차합격` → 1차합격
- **`#N/A`** 등 숫자 칸의 오류 문자열 → 빈 값
- **학생 식별** — 원본에 학번·이름이 없어 `학년도 + 1·2학년 내신`을 학생 키로 씁니다. 3학년 내신은 수시 시트가 3-1까지, 정시 시트가 3-2까지라 값이 달라 키에 쓰지 않습니다
- **계열** — 학과명 키워드로 인문사회 / 자연공학 / 의약보건 / 예체능 분류. 규칙은 `js/parse.js` 상단의 `MED` `ART` `NAT` 배열

## 유지 관리

**매년 데이터 갱신** — 새 학년도 시트가 추가된 엑셀을 「데이터 관리」에서 다시 불러오면 끝입니다. 코드는 건드리지 않습니다.

**계열 분류 수정** — `js/parse.js`의 키워드 배열에 단어를 추가합니다. 위에서부터 의약보건 → 예체능 → 자연공학 순으로 검사하고, 아무것도 걸리지 않으면 인문사회입니다.

**학년별 내신 반영 비중** — 전교과는 학년별 단순평균이 아니라 이수단위 가중평균입니다. `js/parse.js`의 `gradeWeights()`가 명단 전체로 실제 비중을 역산합니다. 2026년 3학년 기준 1학년 43% / 2학년 46% / 3학년 11%였습니다.

## 알려진 한계

- 유사 학생 20명 기준으로는 대학×전형 조합당 표본이 1~2건인 경우가 많습니다. 실제 사례를 보여주는 용도이지 합격 확률로 읽을 수 없습니다
- 수능최저 조건 원문은 2023~2026학년도 시트에만 있습니다
- 성적표의 `국수영사` `국수영과` `수과` 열이 비어 있어 계열별 정밀 매칭은 하지 못하고 전교과로만 맞춥니다
